# Table 2 public result archive

This forward publication view follows the paper's Table 2 method set:
HIPE, RoPE, ALiBi and Legacy NoPE+APE. XPos comparison results remain in
ignored local analysis outputs and are excluded from this archive.

The workbook contains separate endpoint views, fixed sigma/layer statistics,
exact seed values, baseline comparisons and execution attempts. The public
result set has 219 completed seed-runs, 73 complete fixed configurations and
18 previous failed attempts. It includes all 45 new HIPE runs and the archived
Table 2 controls. Nine earlier HIPE runs complete the target grid.

Mean and sample SD use seeds 6198, 1024 and 7 at exactly one sigma/layer
configuration. Best observed HIPE has lower mean PPL than RoPE in 11/12 settings.
Among Table 2 methods, lowest means belong to HIPE in five settings, ALiBi in
six and RoPE in one. These validation-selected gains do not establish significance.

new_run_index.json retains the exact resolved configurations and source
records for the 45 public HIPE runs. Unused implementation-default fields
remain in those configurations for exact provenance. snapshot.json and
artifact_checksums.json identify the current public projection.

The historical research/table2-joint-results-v1-20261104 snapshot is preserved.
It predates this publication-scope change. The full local comparison workbook
and raw inputs have not been modified.
